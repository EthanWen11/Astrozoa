# Astrozoa
Simple 2D asteroids game in openFrameworks
Project for CS134 Computer Game Design and Programming

## Requirements
- openFrameworks (version at time of creation is 0.12.1)
- Visual Studio 2022 (Windows) or other IDE that supports openFrameworks

## Building
1. Download and install openFrameworks
2. Clone this repository into the /myApps/ folder
3. Open astrozoa.sln
4. Build and run in Visual Studio

## Playing
1. Extract the .exe file and /data/ folder
2. Run the .exe file

## Controls and Gameplay
Left and Right arrows to rotate<br>
Forward and Backward to move<br>
Automatic firing occurs in the backward direction, forcing unconventional movement<br>
Score points by destroying asteroids<br>
3 lives; 1 life lost when colliding with asteroid<br>
Difficulty scales with time and firepower scales with score
